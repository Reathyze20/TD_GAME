# Balance sweep — S2 × S3 outcomes, M1 diagnosis

Generated by `scripts/_balance_sweep.gd` via S2's `LevelSimulator`. Section 1 runs
every level × strategy on **each** of 3 seeds (20260829, 20260902, 20260903); a strategy that wins on one
seed and loses on another is a level whose verdict depends on the RNG, which is
itself the finding. Section 2's per-wave detail is emitted for seed 20260829 only.

`wave` is the wave index reached at the time the run ended — win, loss, or TIMEOUT
(the run did not resolve within 10800 simulated frames / 180 simulated seconds,
itself a reportable result, not a harness failure).

**Sections 3–5 are static** — computed from `data/` and `Game`'s constants with no
simulation — so they stay meaningful for a level no strategy can finish.
## 0. Where the run breaks (static verdict)

player has to stop for the run to end above zero: `total leak − (pool − 1)`. `usable

that is the blocks inside `CORE_ROUTINE_RADIUS`, since `in_routine` gates a habit's
FIRING and not merely its placement. `opening buy` is how many of the cheapest
